# 13 · 水墨动态

[目录](./README.md) · [水墨管线](./07-ink-rendering.md)

这一章写 `/fx/` 上的二十四笔动态，以及游戏里怎么触发它们。它们不走 `InkSurface` 的逐笔反馈（那条管线留给角色、道具和画廊），而是一块半分辨率的密度场，全分辨率只做纸纹和三层墨色。着色器是原创的，不是从 inkEngine 抄的。参考片只用来对节奏，仓库里没有那些素材。

真实 GPU、Safari、Firefox 和 60fps 都还没在所有者的机器上测过。无头 SwiftShader 只能说明着色器编得过、生命周期单测是绿的。下面的观感说明以这次无头截图为准，不能写成已经验收。

## 怎么调用

公共入口都在 `src/index.ts`。

```ts
import { InkFxStage, createInkFx, listInkFx } from '@inkgames/engine';

const canvas = document.querySelector('canvas');
if (!canvas) throw new Error('缺少画布');
const stage = new InkFxStage(canvas, { width: 960, height: 540, transparent: true });
const fx = stage.play('splash', {
  speed: 1,
  density: 0.8,
  pigment: 0.25,
  originX: 0.42,
  originY: 0.5,
  keep: false,
  fadeOut: false,
});
stage.update(1 / 60);
stage.dispose();
```

`createInkFx(id)` 不创建 WebGL，单测走这一条。`listInkFx()` 返回 id、中文名、用途、手法、时长、是否循环、能否移位。未知 id 抛出 `未知水墨特效`。

`InkFx` 的生命周期：`start(params)`、`update(dt)`、`progress`、`finished`、`dispose()`。`dispose()` 可以重复调用。循环效果不会自己结束。非循环效果走到时长后停住，之后的 `update` 不再注入新墨，场上的墨留着。

舞台自己没有 `requestAnimationFrame`。宿主每一帧调用 `update(dt)`，`dt` 夹到 0.05 秒。`play` 会停掉上一笔再开始。`seek(seconds)` 按 1/60 秒推进，给静帧用。

| 参数 | 含义 |
|---|---|
| `speed` | 相对规格时长，夹在 0.2–3 |
| `density` | 0–1，乘在注入量上 |
| `pigment` | 色带。`-1` 用效果自己的颜色；`0` 焦墨，`0.25` 朱砂，`0.5` 花青，`0.75` 赭石，`1` 泥金 |
| `keep` | 不擦掉上一笔留下的墨。切片里刀光之后的泼溅用这个 |
| `fadeOut` | 收尾时把整幅墨淡出。叙事标题用，画廊标题不淡出 |
| `originX` / `originY` | 可移位效果的中心，0–1，y 向下。印章在画廊里默认落在右下 |

可移位的效果把笔触写在 `(0.5, 0.5)` 附近，舞台再平移。不能移位的（转场、标题、山、卷轴、地图）忽略这个原点。

## 场上在算什么

模拟目标是半个画布宽、至少 320×180，像素格式 RGBA8：

| 通道 | 内容 |
|---|---|
| R | 当前密度 |
| G | 含水量。水多才扩散，水干了墨冻住 |
| B | 颜料色带 |
| A | 历史最大密度，用来留住已经干的笔痕 |

每帧：curl 噪声平流，沿纸纤维做各向异性模糊，蒸发，最多 16 个墨团注入。注入用 `max`，重复盖上去不会堆成一块死黑。墨团边缘有角向起伏；含水量低时烧进飞白条纹。全分辨率合成再加纸色（新纸 `#EFE8DA`，旧纸往 `#D9C7A2` 走）、墨核、晕带和水痕。水痕用密度的屏幕空间梯度。颗粒来自纤维噪声。

`transparent: true` 时输出预乘 alpha，给 `/story/` 和 `/scroll/` 叠在画面上。山、卷轴、鸟、雨这些覆盖层只让墨本身不透明，免得整张宣纸把底下的场景盖死。

CPU 侧的时间和粒子只用四则、`Math.sqrt` 和 `inkSin` / `inkCos`。着色器里的 `sin`、`atan` 只影响显示。

## 画廊与两处接入

`/fx/` 一卡一笔。悬停时把唯一的 WebGL 画布放进卡片并循环；移开后卡片留下刚才那一帧。点击进入全屏，可以重播，并改速度、浓度、颜色。

查询参数：

| 参数 | 作用 |
|---|---|
| `?fx=drop` | 直接打开这一笔的全屏 |
| `?still=0.4` | 不播。小于等于 1 时当作时长的比例，否则当作秒，然后停在那一帧 |
| `?record=1` | 至少播 3 秒、循环效果最多 6 秒，然后把 `__fxDone` 设为真 |

页面还写 `window.__fxReady`、`__fxId`、`__fxGl`。`scripts/gpu-check.mjs --shots` 会打开 `/fx/`、`/fx/?fx=drop&still=0.5` 和 `/fx/?fx=seal&still=0.5`。

`/story/` 在没有 `?pose=` 时，开场叠一层透明画布播「笔锋显字」，并在过场进入选择时播「晕染转场」。`?pose=` 留给原来的冒烟截图，不盖墨。转场盖住的是同一场戏，不是两张不同的场景图。

`/scroll/` 同样只在没有 `?pose=` 时建舞台。空格攻击时，在角色投影处播「刀光墨痕」，进度过 0.62 再在同一点播「泼墨爆溅」，并保留刀痕。

## 二十四笔

时长是 `speed = 1` 时的秒数。

| id | 名称 | 时长 | 循环 | 手法 | 游戏里用在 |
|---|---|---|---|---|---|
| `drop` | 墨滴晕开 | 4.5 | 否 | 墨滴落下，径向晕开，切向卷须，先湿后干 | 章节开场、受伤、菜单底 |
| `splash` | 泼墨爆溅 | 1.2 | 否 | 主墨团加偏向前方的粒子，飞出时干，着纸后再给水 | 受击、暴击；切片命中 |
| `wipe` | 晕染转场 | 1.4 | 否 | 四角注入，扩散盖住画面，再从中心退潮 | 场景切换；叙事进入选择 |
| `title` | 笔锋显字 | 3.4 | 否 | 三笔写成「水」，起笔顿、收笔飞白，末了一点朱砂 | 标题；叙事开场 |
| `mist` | 云雾出山 | 6 | 是 | 四层山脊噪声，雾的阈值随时间下降 | 开场、大地图 |
| `smoke` | 墨烟云涌 | 4 | 是 | 底部持续注墨，curl 往上卷，淡淡蒸发 | 仙术、传送、乌云 |
| `dissolve` | 墨散成尘 | 1.6 | 否 | 剪影被噪声从一侧吃掉，碎屑被风带走 | 死亡、撤退、字幕消失 |
| `reveal` | 晕染显影 | 2.6 | 否 | 湿墨扩散时被树和山的形状挡住，先灰后有颜色 | 立绘、图鉴 |
| `river` | 墨浪江河 | 4 | 是 | 六条断续水纹，其中一道浪头沿河走 | 江河、水战 |
| `streak` | 飞白疾扫 | 0.9 | 否 | 一道干笔扫过，后半段分成三毫 | 标题底、快切 |
| `rain` | 墨雨烟雨 | 4 | 是 | 视差雨丝，落点在密度场里洇开 | 天气、离别 |
| `seal` | 朱砂印章 | 0.7 | 否 | 印面按下去略微过冲，纸纹吃掉一部分朱砂，带一点墨晕 | 落款、任务完成 |
| `bamboo` | 墨竹生长 | 3.4 | 否 | 自下而上的节、横节、一枝、三片叶 | 章节卡、加载 |
| `plum` | 墨梅绽放 | 4 | 否 | 先干枝，再逐瓣点朱，花心是焦墨 | 冬景、登场 |
| `flame` | 墨焰 | 3.2 | 是 | 上升的笔触，根部朱砂，上端焦墨，卷曲后变细 | 火攻、烽火 |
| `bolt` | 墨雷闪电 | 0.65 | 否 | 先闪一下宣纸，再干笔折线，落点一小团泼墨 | 雷雨、惊变 |
| `slash` | 刀光墨痕 | 0.42 | 否 | 月牙笔势，刃口实、后缘收成飞白 | 普通攻击；切片空格 |
| `scroll` | 卷轴展开 | 1.3 | 否 | 两端轴分开，纸面跟着打开，山影滞后出现 | 书信、地图、圣旨 |
| `ripple` | 墨晕涟漪 | 1.5 | 否 | 中心一小团湿墨，外面几圈断笔圆环 | 点击、踏水、雨点 |
| `condense` | 墨聚成形 | 2 | 否 | 粒子沿剪影收拢，最后勾一圈边 | 登场、召唤 |
| `age` | 墨褪纸旧 | 4.5 | 否 | 纸色走赭，水渍和断笔随时间长出来 | 回忆、旧地图 |
| `flock` | 墨鸟群飞 | 5 | 是 | 八只两笔的鸟，远的淡、近的浓 | 空镜、季节 |
| `map` | 墨染舆图 | 4 | 否 | 先走河道，再皴一道山，最后点三座朱砂城并晕开一块势力 | 大地图、势力 |
| `shock` | 墨晕冲击波 | 0.7 | 否 | 中心一顿，破碎墨环向外，环上留残点 | 范围技能、落地 |

接触表放在 `docs/images/fx/`，挑选的录屏放在 `docs/videos/fx/`。每一笔的完整 webm 留在当次运行的产物目录，不全部进仓库。真实 GPU 未实测。
