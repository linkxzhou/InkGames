# 13 · 美术风格与引擎影响（黑白红武侠水墨剪影）

现行美术方向：**高反差黑白红武侠水墨剪影，参照《影之刃》系列气质并做简化**。完整的风格指南（色板 Hex、笔线、构图、人物、效果、宜忌、英文摘要）见 [video/docs/art-style.md](../video/docs/art-style.md)；生成器共用常量在 [video/tools/art-style.mjs](../video/tools/art-style.mjs)。本文只记录对引擎的影响，供 [plan/10](../plan/10-three-matter-side-scroller-plan.md) 与 [07 · 水墨渲染](./07-ink-rendering.md) 引用。

## 对引擎的影响

| 方面 | 要求 | 落点 |
|---|---|---|
| 色板 | 只用墨黑、四级灰、纸白与一种朱砂红（`#141414 #3a3a3a #6e6e6c #a8a8a4 #d2d1cc #eceae4 #b3241c`）；红色只给血、日、旗、印 | `src/core/ink-palette.ts` 的 36 色保留给笔刷库，历史内容只取这 7 色；章节点缀色不进画面 |
| 人物 | 黑色剪影为主，轮廓可读优先，内部最多两三块焦灰；几乎不画五官 | 角色用平涂墨面 + 粗边笔画即可，不需要细节贴图与表情骨骼 |
| 打击效果 | 命中/高潮时大块泼墨 + 斜向朱红血雾喷溅，随后定格 | 需要一个“泼墨/血雾”盖章效果（可复用 InkSurface 的洇染 stamp，颜色取朱砂红），以及定格/时间缩放 |
| 背景 | 三到四层平涂灰阶的远山、雾、竹、建筑剪影，视差滚动 | 横版视差层即可，不做皴法与界画线；减少每帧笔画数量 |
| 动势 | 枯笔飞白拖尾表示动作方向 | 运动拖影（trail）沿速度方向绘制，替代复杂动画帧 |
| 构图 | 侧视，地平线在下三分之一 | 与 three.js 正交相机 + Matter.js 的 X/Y 平面一致 |

不采纳：金色高光、蒸汽朋克机械、细密界画线条、PBR 材质与光效粒子。
