# PDF → Markdown 转换规范

目标：把一本或多本 PDF 历史书转成——
1. **保留页码**：每条内容可回溯到 PDF 物理页码（及书内印码，若能识别）
2. **Obsidian 兼容**：纯 Markdown + YAML frontmatter

## 0. 环境准备

```bash
python3 -c "import fitz" 2>/dev/null || pip install pymupdf
```

若 PDF 无文字层（扫描件），还需 OCR 手段（见 §4）。OCR 依赖（Tesseract chi_sim / OCRmyPDF）或环境可用的 OCR 工具（如 PaddleOCR MCP、在线 OCR 服务）。

## 1. 检测 PDF 类型

用 PyMuPDF 提取第一页文本：
- 字符数 ≥ 20 → 文本型，走 §2
- 字符数 < 20 → 扫描件，走 §4 OCR 流程

竖排古籍/双栏排版：提取后检查阅读顺序，错乱时按栏拼接（先左栏后右栏）。

## 2. 文本型 PDF 逐页提取（主路径）

对每一物理页 p（从 1 开始）：

1. `page.get_text("text", sort=True)` 提取该页文本（sort 尽量保持阅读顺序）。
2. 清理页眉页脚噪声：每页固定位置重复出现的书名、页码数字等短串。
3. 以 `〔p.{p}〕` 开行写入输出文件，页与页之间空一行。

伪代码：

```python
import fitz
doc = fitz.open(pdf_path)
with open(out_md, "w", encoding="utf-8") as f:
    for p in range(1, doc.page_count + 1):
        text = clean(doc[p].get_text("text", sort=True))
        f.write(f"〔p.{p}〕\n{text}\n\n")
```

补充规则：
- **章节标题**：若 PDF 有目录书签，按书签位置把对应页开头插入 `#`/`##` 标题（放在该页页码标记之后）。
- **表格**：文本提取成列错乱时，可尝试 `page.find_tables()` 转 Markdown 表格；仍错乱则保持原样并加提示 `> 表格提取可能失真`。
- **插图**：页内如有图片，在该页标记处加 `（本页含插图 N 幅）` 占位说明。
- **引文/注释**：脚注按顺序并入正文行尾，加 `〔注N〕` 标记。

## 3. 书内印码（印刷页码）识别（尽力而为）

历史书常有前置部分（序/目录），物理页码 ≠ 印刷页码。启发式：若每页文本首/尾出现孤立整数，且相邻页差值恒为 1，判定为印码，记录 `印码偏移 = 物理页码 - 印码`。

- 识别成功：页码标记写 `〔p.{物理}·印{印码}〕`
- 识别失败：只用 `〔p.{物理}〕`，frontmatter 注明"未识别印码"

## 4. 扫描件 OCR 前的能力检查

扫描件（首页字符数 < 20）需要 OCR 或读图能力。动手前先做三项检查：

1. **环境有无 OCR 工具**：`ocrmypdf -l chi_sim`、`tesseract`、PaddleOCR MCP 等；
2. **模型有无读图能力**：能否用 Read 工具直接查看渲染出的页面 PNG（渲染参考：PyMuPDF 150–300 dpi）；
3. **用户有无替代输入**：已有 .txt/.md/.docx 文本或 OCR 结果。

### 4.0 两者皆无 → 必须反馈用户并暂停

若**无 OCR 工具、模型不能读图、也无替代文本**，不得强行硬转或凭记忆编造，立即向用户反馈，内容须包含：

- **情况**：该 PDF 为扫描件/图片版，没有文字层；当前环境既无 OCR 工具可用，模型也不具备读图能力，无法准确提取文字。
- **影响**：无法建立逐页可信文本，"页码即证据"的原则将落空，三体笔记条目无法溯源。
- **建议**（择一即可）：
  a. 提供带文字层的 PDF 或电子版（出版社电子书、已 OCR 版本）；
  b. 提供已有的文本/OCR 文件（.txt/.md/.docx），直接进入整理环节（跳过转换）；
  c. 安装 OCR 工具（如 PaddleOCR、Tesseract + chi_sim）后重试；
  d. 换用具备读图能力的模型环境，或用在线 OCR 服务先生成文本。
- 在用户答复前暂停该书的转换。

### 4.1 仅模型可读图（无 OCR 工具）

可用 Read 逐页看图转录，但必须：
- 在产物页标记处加 `〔OCR 存疑〕` 提示；
- 明确告知用户此方式的精度风险与工作量；
- 生僻字不猜测改写，保留原样并标注。

### 4.2 有 OCR 工具

按以下流程处理：

1. **OCRmyPDF + Tesseract**：`ocrmypdf -l chi_sim in.pdf out.pdf`，输出带文字层的 PDF，再走 §2 逐页提取。
2. **环境 MCP OCR 工具**（如 PaddleOCR）：用 PyMuPDF 把每页渲染成 PNG（150–300 dpi），逐页送 OCR，按 §2 装配页码标记。
3. 识别不出的生僻字：保留原样并加 `〔OCR 存疑〕` 标记，不猜测改写。

OCR 完成后随机抽 3 页与原图核对，确认无乱序。

## 5. 输出文件格式

每个输出 `<书名>.md` 结构：

```markdown
---
书名: 《书名》
作者: 作者名
来源: 文件名.pdf
物理页数: 987
印码偏移: 未识别 / 偏移 N 页
转换日期: 2026-07-31
tags: [史家三体/源文本]
---

# 《书名》· 原文转录

> 每页以〔p.N〕标记开头。引用时写作〔p.N〕或〔《书名》p.N〕。

〔p.1〕
……正文……
〔p.2〕
……
```

## 6. 质量检查

- 物理页数 × 平均每页字符数 与文件大小量级吻合，明显缺失则重跑。
- 抽查 5 个页码标记，确认对应页文本非空。
- 整本书若有个别页提取为空，逐页打印该页字数定位问题页。
