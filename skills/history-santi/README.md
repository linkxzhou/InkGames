# history-santi · 史家三体

历史类书籍的三体阅读辅助笔记工具。把历史类 PDF 书籍转化为三套互为经纬的阅读辅助笔记：**长编体**（编年）、**纪传体**（人物）、**本末体**（大事）。全部产物保留页码以便查证，兼容 Obsidian。

史家三体，其源有自：

> 古之史策，编年而已，周以前无异轨也。司马迁作《史记》，遂有纪传一体，唐以前亦无异轨也。至宋袁枢以《通鉴》旧文，每事为篇，各排比其次第，而详叙其始终，命曰"纪事本末"，史遂又有此一体。——《四库全书总目》卷四十九"纪事本末类"

## 功能特性

- **三体笔记**：长编体编年史（全部事件按时间排比）、纪传体人物志（人物小传 + 可拖拽可编辑的人物关系网 HTML）、本末体大事记（重大事件起因—经过—结果—影响—疑点）
- **页码保留**：每条笔记可回溯到 PDF 物理页码；跨书引用标注书名
- **Obsidian兼容**：全部 .md 带 YAML frontmatter 与双链，页码引用统一格式
- **人物关系网**：单文件自包含 HTML，支持拖拽、增删节点/连线、搜索、阵营过滤、主题切换、localStorage 自动保存、导入导出 JSON，双击即可离线打开
- **扫描件处理规范**：内置 OCR 能力检查与用户反馈流程（`references/pdf-conversion.md`），无 OCR 工具且模型不能读图时如实反馈

## 安装

将本目录（`history-santi/`）放到 skill 目录下：

```
~/.agents/skills/history-santi/
```

Windows 示例：`C:\Users\<用户名>\.agents\skills\history-santi`

## 使用

对用户说"读历史书 / 生成三体笔记 / PDF 转笔记"等即可触发（触发词详见 SKILL.md 描述）。典型流程：

1. 提供历史类书籍 PDF（或已有的 .txt/.md/.docx 文本）
2. 转换 PDF → 保留页码的 Markdown（`00_源文本/`）
3. 规划性通读，分批建立事件/人物/大事三张索引
4. 生成四份产物：长编、人物志、人物关系网 HTML、大事记
5. 校验与交付报告
