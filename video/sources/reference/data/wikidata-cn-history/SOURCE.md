# SOURCE: Wikidata SPARQL 导出（CC0）

- 接口：https://query.wikidata.org/sparql
- 许可证：**CC0 1.0**（Wikidata 结构化数据）
- 导出日期：2026-10-12（box 时区 UTC+8 上午）
- 文件：
  - `emperors_of_china.csv`：所有有 P39 = Q268218（中国皇帝）职位声明的人物，带任期起止（pq:P580/P582）、所属政权（pq:P1001）、前任/继任、结束原因、生卒。共 554 行（一人可能有多段任期或多个政权）
  - `era_names.csv`：P31 = Q256408（年号），942 行；只有约 236 条带起止时间，但前后年号链（P155/P156）比较完整
  - `chinese_dynasties.csv`：P31 = Q12857432（中国朝代），60 行，带建立/灭亡时间、首都、前后朝代（首都有多个时一个朝代会占多行）
- 注意：Wikidata 的日期统一用 `-01-01` 表示"只精确到年"，公元前年份用天文纪年（-0205 = 公元前 206 年），读取时要换算；数据来自社区编辑，只能作为交叉核对的第三方来源。
