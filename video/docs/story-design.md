## 0. 一句话与设计支柱

**一句话**：用 InkGames 的水墨笔刷，把中国从上古到清的历史画成一卷可以“走进去”的长卷。每一段历史先用一段水墨动画讲正史，然后由玩家决定：沿正史走一遍，还是走进野史和演义的那个版本。

设计支柱：

1. **画即叙事**：开场动画、转场、题字、战斗痕迹都用引擎的笔刷“画”出来，而不是贴图播放。墨迹本身就是信息，比如刀扫过的飞白、马蹄印、被水刷洗掉的桥。
2. **正史为经，野史为纬**：正史线是骨架，必须可查证。野史线是同一事件的另一种讲法，明确标注出处类型（演义、笔记、民间传说），不冒充史实。
3. **一事一局**：一个场景就是一个故事、一段玩法，10–25 分钟能玩完。场景之间靠时间线串起来，不靠长篇连续剧情。
4. **史评卷轴**：每个场景结束后展开一张“史评”，并列正史与野史的说法，列出史源和“考异”。这是把“好玩”和“可信”接起来的环节。

## 1. 结构：章 → 场景 → 剧情图 → 时间线

```text
游戏（一卷长卷）
└─ 章（Chapter）= 一个朝代或时期，如「战国」「秦」「楚汉·西汉」
   └─ 场景（Scene）= 一个故事 = 一段玩法，如「易水寒 · 荆轲刺秦王」
      ├─ 开场动画（Opening）：水墨 + 旁白 + 音乐，讲正史
      ├─ 抉择（Fork）：执正史之笔 / 循野史之墨 /（可选）推演
      ├─ 剧情图（Plot graph）：节点 = 剧情段落（beat），边 = 选择或条件
      │   ├─ 正史分支：玩法 + 演出，结局与史实一致
      │   └─ 野史分支：玩法 + 演出，结局可能与史实相同（汇流）或不同（歧出）
      ├─ 结局（Ending）：正史结局 / 野史结局 / 异闻结局 / 失败（可重试）
      └─ 史评卷轴（Coda）：正史与野史对照、史源、考异
```

- **树形**：章是树干的分段，场景是枝，剧情图是叶脉。剧情图本身是有向无环图（DAG），允许汇流，不允许环（重试由运行时处理，不画成环）。
- **每个节点都有时间**：章、场景、剧情节点、结局都带 `when`（公元纪年区间 + 精度 + 中国纪年显示），以及 `timeline` 归属（正史 / 野史 / 推演）。时间线 UI 由这些字段直接生成，不另外手工维护。
- **历史锚点（anchor）**：每个场景至少有一个“入口锚点”和一个“出口锚点”，都是正史事件。下一个场景总是从正史的入口锚点开始，这保证 100 多个场景组合起来不会爆炸。

### 1.1 一个场景的标准流程

| 步骤 | 内容 | 时长参考 | 可跳过 |
|---|---|---|---|
| 1. 卷轴展开 | 时间线上点亮该场景的节点，题写场景名（书法） | 3–5 秒 | 否（可加速） |
| 2. 开场动画（正史） | 水墨笔画、镜头、旁白、音乐、音效；结尾停在“历史的岔口” | 45–120 秒 | 二周目起可跳过 |
| 3. 抉择 | 两（或三）方印章：「正史」「野史」（「推演」需解锁） | 玩家决定 | 否 |
| 4. 分支剧情 + 玩法 | 由剧情图驱动，玩法模板见 §5 | 8–20 分钟 | 否 |
| 5. 结局 | 结局演出（水墨） | 15–40 秒 | 可跳过 |
| 6. 汇流或歧出 | 回到正史出口锚点，或记入「异闻录」 | 5 秒 | 否 |
| 7. 史评卷轴 | 正野对照、史源、考异、解锁的史料卡与人物卡 | 玩家自读 | 可跳过 |

## 2. 分支设计：怎么分叉、怎么汇流

### 2.1 三类线

| 线 | 定义 | 标注 | 能否改变结局 |
|---|---|---|---|
| 正史（canon） | 依据正史原典（二十四史、《资治通鉴》、出土文献等）可以查证的经过 | 墨色实线，印章「正史」 | 不能。玩家影响的是“怎么经历”和评分，不是结果 |
| 野史（legend） | 演义、笔记、民间传说、戏曲里流传的版本 | 朱色实线，印章「野史」，并标出处类型 | 可以，但只有该版本本来就这么讲时才行 |
| 推演（what-if，可选） | 游戏原创的假设，例如“若秦舞阳不惧” | 淡墨虚线，印章「推演」 | 可以。结果只进入异闻录，不影响后续场景 |

推演线默认关闭，可以在完成某场景的正史和野史两条线后解锁。它是原创虚构，所以必须在 UI 和史评里写明“此为推演，非史实”。

### 2.2 分叉点

- 默认分叉点在开场动画末尾。开场讲到“历史的岔口”就停，比如图穷匕见的前一刻。
- 场景内部还可以有 0–2 个次级分叉，例如野史线里再选“信琴声”或“不信”。次级分叉不能跨线：正史线内部的选择只改经历和评分，不改结局。
- 每个分叉最多 3 个选项，避免一个场景内的组合爆炸。

### 2.3 汇流与歧出

- **汇流（merge）**：野史线的结局与正史一致，只是经过不同。例如野史里秦王听琴声脱险，荆轲同样被杀。汇流后回到正史出口锚点，时间线上朱线并回墨线。
- **歧出（diverge）**：野史或推演的结局与正史不同，例如《封神演义》里众神封位。歧出结局记入「异闻录」（一个独立的支线时间轴），点亮对应的朱色或淡墨节点。**下一个场景照样从正史入口锚点开始**，不继承歧出状态。
- **章内长线异闻（可选，限制深度 2）**：同一章内允许最多两个场景共享一个野史状态旗标，比如《隋唐演义》的瓦岗群像连续两场，用来写演义里的人物弧线。跨章禁止，避免状态蔓延。

### 2.4 结局类型

| 结局 | 触发 | 演出 | 计入 |
|---|---|---|---|
| 正史结局 | 正史线通关 | 标准水墨结局 + 史实旁白 | 主线进度、章完成度 |
| 野史结局 | 野史线通关 | 野史专属演出，开头写出处（如“《东周列国志》第一百七回载”） | 野史收集度；汇流的还计入主线 |
| 异闻结局 | 推演或歧出 | 淡墨、半透明演出，题“异闻” | 异闻录 |
| 失败 | 玩法失败 | 墨迹被水洗掉（`InkWash.wash`），回到最近的检查点 | 不计 |

### 2.5 评分：墨评

正史线不能改结果，所以要给玩家另一种目标。每次通关按三项给“墨评”（甲乙丙）：**史识**（在剧情里做出合乎史实的判断，比如礼仪、称谓、时机）、**笔意**（玩法表现：命中、连击、节奏）、**寻迹**（发现场景中的史料彩蛋）。墨评只影响收集和成就，不卡主线。

## 3. 解锁与进度

- **章节解锁**：章按时间顺序解锁。完成上一章的“关键场景”（每章 2–3 个，在 [章节大纲](./chapter-outline.md) 里加粗）的正史线，解锁下一章。可以乱序玩已解锁的场景。
- **野史线解锁**：看过该场景的开场动画即可选择，不必先通关正史，因为两条线是平行的讲法。
- **推演线解锁**：同一场景的正史线和野史线都通关后解锁。
- **收集**：史料卡（事件，带史源）、人物卡（纪传，带关系网）、印章（墨评甲）、器物（道具笔刷皮肤）。人物卡的关系网复用 history-santi 的关系网结构，样例见 [`11-history-game-data/05-09-jingke-relations.html`](../viewer/05-09-jingke-relations.html)。
- **存档**：以场景为单位存档，场景内有检查点（剧情图上标 `checkpoint: true` 的节点）。存档内容见 [内容数据格式 §2.8](./content-schema.md#28-存档与进度)。

## 4. 时间线 UI：一卷长卷

- **形态**：横向手卷，从右往左展开（古籍阅读方向），也可设置为从左往右。卷轴分段对应各章，段首题朝代名。
- **刻度**：上古和三代用“约”刻度（只标相对先后，不标精确年）；自前 841 年共和元年起用公元年刻度。刻度密度按时期分段线性，避免先秦把卷轴拉得过长。
- **节点**：场景节点按 `when.start` 落在刻度上，节点形状表示状态（未解锁：留白；已解锁：淡墨圈；通关正史：浓墨圈；通关野史：加朱印）。
- **三条线**：正史墨线在中轴；野史朱线在上方，从分叉点出、在汇流点回；推演淡墨虚线在下方，止于异闻节点。
- **对照模式**：长按节点，上下分屏同时显示正史与野史的结局画面和史评摘要。
- **纪年显示**：主显示公元（“前 227 年”），副显示中国纪年（“秦王政二十年”）。没有把握的纪年显示“约”，并在史评里写明依据。
- **实现**：时间线是一个独立的 three.js 场景：一张长卷平面，墨迹画在它的动态纹理上（与地形墨散同一套“笔刷 → 渲染目标”管线），节点与连线用 `marker` / `pen` 笔刷画，正交或长焦相机沿 X 平移。详见 [12 §3](./engine-gaps.md#3-引擎缺口清单)。

## 5. 玩法模板（按场景类型）

现有十个道具（`PROP_BRUSHES` / `ITEM_PRESETS`：sword、blade、spear、bow、shield、war-horse、banner、ink-bomb、water-brush、boat）就是玩法的“动词”。场景按类型复用模板：

| 模板 | 核心动词（道具） | 代表场景 | 引擎依赖 |
|---|---|---|---|
| 刺杀 / 决斗 | sword、blade（swing）、shield（guard） | 荆轲刺秦王、鸿门宴舞剑、温酒斩华雄（野史） | 武器扫掠体（现 plan/10 列为待办）、骨骼角色 |
| 战阵 | spear（thrust）、banner（wind，旗语与士气）、war-horse（gallop） | 长平、巨鹿、官渡、萨尔浒 | 群体单位（boids 或简单编队）、地形墨晕（3D 墨散动态纹理） |
| 守城 / 攻城 | shield、bow（projectile）、ink-bomb（blast，火攻与炮） | 睢阳、钓鱼城、北京保卫战、宁远 | Matter 投射物、可破坏墨墙 |
| 水战 / 渡河 | boat（wake）、ink-bomb（火船）、water-brush | 赤壁、淝水、采石、鄱阳湖、崖山 | flow / distort 水面、舟体物理 |
| 治水 / 工程 | water-brush（erase，改碰撞几何）、spear 作夯 | 大禹治水、都江堰（待定）、大运河、郭守敬 | 水刷改 CPU 碰撞几何（现由 `Playfield` / `InkWorld` 承担）、水流表现 |
| 奔袭 / 出使 | war-horse、bow、banner（方向） | 张骞出使、苏武、班超、玄奘西行 | 长卷横版移动、地图段落 |
| 庙堂 / 辩论 | 笔（自由笔画写字）、印章 | 完璧归赵、负荆请罪、舌战群儒（野史）、商鞅变法 | 对话与选择 UI、书法输入（P2） |
| 解谜 / 寻迹 | water-brush 洗出隐藏墨迹、笔画补全 | 伍子胥过昭关、建文帝出亡（野史）、顺治出家（野史） | 遮罩 pass、隐藏层 |
| 山林 / 竹林 | blade、ink-bomb（墨溅断竹）、sword | 竹林刺杀、山道伏击（如 13-02 玄武门外景、19-07 戚家军丛林） | 三维皴法山石（随相机距离变化的笔触描边 + Perlin 噪声）、竹子骨骼摇摆与顶点着色器撕裂成粒子 |
| 应对时机（dialogue-timing） | 印章、笔；在对话的节拍点上出言或沉默 | 渑池之会、鸿门宴、杯酒释兵权、戊戌变法 | 节拍条 UI、与 vo/字幕同步的时间窗 |
| 书法（calligraphy） | 笔（自由笔画写字、题壁、勒石） | 燕然勒石、兰亭、正气歌、万言书 | 书法输入与笔顺比对（P2）、印章 |
| 寻迹（trace） | water-brush 洗出隐藏墨迹、沿墨线追踪 | 包公断案、建文出亡、马可·波罗行纪 | 遮罩 pass、隐藏层、地图标记 |
| 求生 / 撤离（survival、evacuate） | shield、boat、war-horse；护送与资源 | 靖康北迁、崖山、扬州十日（只写史实、不以平民为目标） | 护送 AI、资源计数、失败重试 |
| 宴席 / 伏击 / 夜袭 / 突围 / 骑战（banquet、ambush、night-raid、breakout、cavalry） | 上表动词的组合 | 鸿门宴、好水川、昆仑关、垓下、萨尔浒 | 同战阵与潜行 |

**数据里的使用频度**（157 个场景、759 个玩法节点，2026-10 统计）：court 119、dialogue-timing 111、riddle 65、stealth 56、siege 44、calligraphy 43、battle 42、cavalry 42、naval 40、trace 37、journey 32、engineering 32、survival 22、duel 19、night-raid 18，其余个位数。也就是说，**对话、时机与解谜类节点占了四成以上**，引擎排期应先保证庙堂 / 对话 UI 与 water-brush 解谜，再做大规模战阵（见 [12 §3](./engine-gaps.md#3-引擎缺口清单)）。

每个模板做成一个玩法插件（沿用现有 `itemId / requiresEffects` 组合契约的思路，迁到 three.js 后按新引擎的插件协议实现），场景数据只填参数，不写逻辑。新引擎计划中的三项效果正好对应历史场景的常见画面：**地形上的 3D 墨散**（战场、行军、马蹄）、**皴法山石**（山水开场、关隘）、**墨溅断竹**（竹林决斗、伏击）。

## 6. 写作规范

### 6.1 原创与版权（硬性）

- **游戏内所有文字都是原创写作**：旁白、对白、字幕、史评、卡片说明，都由我们自己写。
- 语料库里的现代作品（如《明朝那些事儿》《大秦帝国》《那时汉朝》《边荒传说》《五千年演义》系列等，见 [书目](../data/corpus-catalog.json)）**只作研究和灵感参考**，不得复制或改写其段落、对白、独特情节设计和章节标题文字。
- 可以直接引用的只有公有领域的古籍原文（如《史记》《三国志》《东周列国志》《三国演义》《封神演义》），每处引用标出处，单次引用不超过两句，并附白话。
- 蔡东藩《历朝通俗演义》：作者卒于 1945 年，按中国著作权法（作者终生加 50 年）已于 1995 年底进入公有领域。为稳妥起见（海外发行地的保护期可能更长），本项目对它**仍只引书名与回目、不录原文**，与现代作品同样处理；数据里的第二条线凡据蔡著改编的，都标“演义”并写明回目与本地语料页码。
- 语料库 PDF 不进入公开仓库，也不进入发布物。`.gitignore` 已加 `thirdparty/Chinese_History-master*`（本地修改，未提交）。

### 6.2 史实

- 正史线每个剧情节点都要有 `sources`，至少一条正史原典出处（书名 + 篇名），可选附语料库页码。
- 年代：先秦用“约”；有争议的年份（如马陵之战前 342 / 前 341）写主流说法，在 `notes` 里列异说，UI 标“约”。
- 数字（兵力、伤亡）一律加“史载”二字，不当作确数。
- 待核验流程：写作时不确定的事实标 `verify: "pending"`，内容校验器在发布构建中拒绝任何 `pending` 的正史节点（见 [内容数据格式 §4](./content-schema.md#4-校验与测试)）。
- 出处写法：书名 + 卷 / 篇 / 回（如《史记·刺客列传》《续资治通鉴长编》卷二、蔡东藩《宋史演义》第七回），演义与语料书再附本地语料页码；不能确认卷次的不写，宁缺不编。正史节点的 `when` 必须落在入口与出口锚点之间，校验器会检查。
- 正史与野史混淆的常见坑（2026-10 回查时改正过的）：把演义情节写进正史线（如萨尔浒、虎门销烟的细节）、把笔记当正史（如“立马吴山”诗出《大金国志》而非《鹤林玉露》）、回目号与页码错位、伪书当史料（如《致身录》）。遇到这类情况，正史线只保留原典有的部分，其余移到第二条线并标明性质。

### 6.3 野史

- 每条野史线写明出处类型：`novel`（演义小说）、`biji`（笔记）、`folk`（民间传说）、`opera`（戏曲）、`modern`（现代作品）。
- 野史的出处若是现代作品，只能借用“流传的说法”这一层，例如“民间流传崇祯太子尚在”。不得借用该作品原创的情节与人物。
- 野史开场必须有一句标识：“此为野史所载 / 民间所传”。

### 6.4 语气与价值

- 不美化屠杀与酷刑。涉及屠城、坑杀、酷刑的事件，开场只交代史实，画面用留白、飞白、墨散来表现，不做血腥特写；玩法里不把平民作为目标。
- 各民族政权（辽、西夏、金、元、清等）以平等视角叙述，不使用侮辱性称谓；“胡”“虏”等古称只出现在古人引语里，并在史评中说明。
- 近现代（1840 年以后）与民国：首版只做晚清少量场景，写法以史实陈述为主；民国章默认不做（见 [章节大纲 §22](./chapter-outline.md#22-民国可选默认不做)）。

### 6.5 文风与长度

- 旁白：浅近文言与白话之间，每句 ≤ 24 字，每段开场旁白 ≤ 180 字（约 60 秒朗读）。
- 对白：人物各有声口，不用网络流行语；称谓合乎时代（战国称“王”“大王”，不称“陛下”）。
- 字幕：横排每行 ≤ 18 字，竖排每列 ≤ 12 字；同时最多 2 行。
- 场景标题：四字或五字主题 + 事件名，例如「易水寒 · 荆轲刺秦王」。

## 8. 语料分析结论（2026-10-09）

按 `skills/history-santi` 的方法做了第一轮“规划性通读”：转换、建索引、定位。完整的三体笔记（长编、纪传、本末）要逐书分批通读，单次会话做不完，按场景需要逐个补。

- **语料构成**：`5000-year_History/e-book/` 16 册是《五千年演义》丛书（现代通俗演义，章回体），不是正史原典。本计划把它当作“正史线的叙事参考”，正史线的事实仍须回查《史记》《资治通鉴》等原典。`野史/` 31 册里有正史原典 1 部（《三国志》陈寿撰、裴松之注），古典演义 5 部（《三国演义》《东周列国志》及其上下分册、《封神演义》《隋唐演义》），蔡东藩历朝演义 8 部，其余为现代作品。书目、作者、版权状态见 [`11-history-game-data/corpus-catalog.json`](../data/corpus-catalog.json)。
- **扫描件**：e-book 16 册全部是图片版（Pdg2Pic），没有文字层。本轮只用 Tesseract（chi_sim）识别了各册目录页。识别质量一般，回目文字要人工核对。正文 OCR 尚未做。
- **文件名与内容不符**（已按回目和自序逐册核对）：`隋朝.pdf` 实为蔡东藩《南北史演义》；`北宋.pdf` 实为《五代史演义》；`南宋.pdf` 实为《宋史演义》（覆盖两宋）；`唐朝/元朝/明朝/清朝/民国.pdf` 对应蔡东藩各朝演义；`民国往事.pdf` 是现代网络穿越小说，不能当史料；`qianqinshenshi` 是《前清盛世》（清前期），不是前秦。
- **覆盖缺口**：《五千年演义》这一套里没有南北朝分册，南北朝的叙事参考只有《南北史演义》（`隋朝.pdf`）和《中国上下五千年》。
